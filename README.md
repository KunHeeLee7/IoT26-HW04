# IoT26-HW04  

### **Objective**
* Learn how to create a standalone web server with a Raspberry Pi using the Flask framework.
* Control and toggle two LEDs (or other outputs like a relay or transistor) connected to the Raspberry Pi GPIOs via a web interface.

### **Tasks Performed**
* **Environment Setup**: Configured the Raspberry Pi and installed the Flask web framework along with necessary dependencies.
* **Hardware Wiring**: Connected two LEDs and appropriate resistors to the Raspberry Pi GPIO pins based on the circuit schematic.
* **Web Server Development**: Developed a Python script using Flask to host a local web server that handles HTTP requests to toggle the GPIO states.
* **User Interface**: Created an HTML/CSS interface allowing users to control the LEDs remotely from any browser on the network.

### **Development Environment**
* **Device**: Raspberry Pi
* **Language**: Python 
* **Framework / Library**: Flask, RPi.GPIO (or standard GPIO library) 
* **Tools**: SSH, Visual Studio Code (VS Code), Web Browser
